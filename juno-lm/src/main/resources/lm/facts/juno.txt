# ===== Compiler report =====
What is the runtime risk report? | What does the compiler report? => Arena use and warnings such as JUNO-RISK-001, printed by juno:compile.
What is JUNO-RISK-001? | What does JUNO-RISK-001 mean? | Explain JUNO-RISK-001 | JUNO-RISK-001 warning? => An allocation can repeat in a loop and may exhaust the arena.
What is JUNO-RISK-002? | What does JUNO-RISK-002 mean? | Explain JUNO-RISK-002 | JUNO-RISK-002 warning? => The arena estimate may not fit, assuming no garbage collection.
What is JUNO-RISK-003? | What does JUNO-RISK-003 mean? | Explain JUNO-RISK-003 | JUNO-RISK-003 warning? => A recursive call cycle makes the stack depth unbounded.
What is JUNO-RISK-004? | What does JUNO-RISK-004 mean? | Explain JUNO-RISK-004 | JUNO-RISK-004 warning? => Array accesses without a compile-time bounds proof.
What is JUNO-RISK-005? | What does JUNO-RISK-005 mean? | Explain JUNO-RISK-005 | JUNO-RISK-005 warning? => A division or remainder may receive a zero divisor.
What happens with unsupported Java? | What if I use an unsupported feature? => Juno stops at link time with a CompileException naming it.
What is a CompileException? | Why did my program fail to compile? => Juno found something outside its Java subset or the board's capabilities.

# ===== Concurrency =====
Does Juno support threads? | Can I use threads? => Yes, virtual threads run on carriers.
How do I start a thread? | How do I create a virtual thread? => Thread.startVirtualThread with a Runnable.
What is a carrier? | What runs virtual threads? => A native thread that runs Juno's virtual threads.
How many carriers does the Nano ESP32 have? | Does the ESP32 use both cores? => Two, one per core.
How many carriers does the Portenta H7 have? | Does the Portenta use the M4? => Two: the Cortex-M7 and the Cortex-M4.
How many carriers does the UNO R4 have? => One.
How many threads does the UNO R3 have? | Can the UNO R3 run threads? => At most four scheduler slots, including main.
Is the scheduler preemptive? | How long is a time slice? => Yes, with a 1 ms time slice per carrier.
Is structured concurrency supported? | Can I use StructuredTaskScope? => Yes, StructuredTaskScope and ScopedValue.
Is synchronized supported? | Can I use locks? => Yes: synchronized, ReentrantLock, read-write locks and conditions.
Are atomics supported? | Can I use AtomicInteger? => Yes: AtomicInteger, AtomicLong and AtomicBoolean.
Which java.util.concurrent classes work? | Is CountDownLatch supported? => CountDownLatch, Semaphore, CyclicBarrier and Phaser.
Does wait and notify work? | Can I use Object.wait? => Yes, inside synchronized; wait(long) is not supported.
How do I protect a shared counter? | Is count++ thread safe? => No. Use an atomic, synchronized or a lock.

# ===== Memory =====
How does Juno use memory? | What is the memory model? => Code and constants in flash; data, arena and stacks in RAM.
What is the arena? | Where do objects live? => One fixed block of RAM for everything allocated with new.
Is there a garbage collector? | Does Juno collect garbage? => Yes, a conservative mark-and-sweep collector.
Does the collector move objects? | Do object addresses change? => No. Objects never move.
Is there a Java heap? | Is there a general heap? => No. Only the fixed arena.
What happens when the arena is full? | What if the arena runs out? => It stops with a serial message; there is no OutOfMemoryError.
Should I allocate in the main loop? | Can I create objects in the loop? => No. Allocate buffers once at startup.
What is zero allocation? | Why avoid allocation? => Allocate at startup and reuse buffers, so the arena never fills.
How big is the arena on the UNO R3? | UNO R3 arena? => 1 KiB.
How big is the Juno arena on the UNO R4? | What is the UNO R4 arena? | How big is the arena on the UNO R4 WiFi? => 8 KiB.
How big is the Juno arena on the Nano ESP32? | ESP32 arena? => 64 KiB.
How big is the arena on the Portenta H7? => 64 KiB.
How big is the arena on the Pico 2 W? => 64 KiB.
How big can the arena be on the Nano ESP32? => Up to 296840 bytes.
What is PSRAM? | How do I use PSRAM? => External RAM; Juno exposes it as explicit Psram buffers.
Which boards support Psram? | Where can I use Psram? => The Nano ESP32 and the AI Thinker ESP32-CAM.
How do static initializers run? | When do static blocks run? => At startup, before main, in a fixed order.
