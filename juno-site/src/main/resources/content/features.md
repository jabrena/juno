- **[Java subset](../java-subset):** the language itself, grouped by topic: data types, the program's entry point,
  object-oriented programming, control flow, arrays, lambdas, exceptions, concurrency and the JDK classes Juno supports.
  Start here to learn what Java code runs on the board.
- **[Memory model](../memory-model):** how a program uses the microcontroller's memory: flash and RAM, startup, the
  stack, the fixed 8 KiB arena and its garbage collector, the `juno.*` memory flags, and how many threads and arrays each
  board can hold.
- **[JLS 17 conformance](../jls-17-conformance):** how Juno maps each section of the Java Language Specification's
  Memory Model (chapter 17) to a focused example and to the boards it runs on.
- **[Board features](../board-features):** what each board supports beyond the language: Wi-Fi, HTTP and email,
  Bluetooth, USB, displays, storage and shields, compared board by board in one table.
