Java, compiled straight to the board

Juno is an ahead-of-time compiler for running a practical subset of Java for microcontrollers.

Get started Try Juno See the code

Embedded

Juno runs on the Arduino UNO R3, UNO WiFi Rev2, UNO R4 WiFi and UNO Q, on the Arduino Nano ESP32 and on the M5Stack Cardputer. GPIO, timing, Serial, the LED matrix, Wi-Fi, HTTP, JSON, SD cards, USB HID and LCD/TFT shields are plain Java native methods lowered to shim calls at link time.

Ahead of time

javac → .class → Juno's closed-world linker → AVR, Thumb-2 or Xtensa assembly plus an extern "C" runtime shim, assembled and linked by the board's own Arduino toolchain. Everything runs from one fixed arena, so nothing is interpreted and nothing is loaded at runtime.

Try Juno

Write plain Java, then let the Maven plugin compile, verify and flash it.

Blink.java
{|import io.github.jabrena.juno.hardware.ArduinoUno;
import io.github.jabrena.juno.hardware.gpio.DigitalOutput;
import io.github.jabrena.juno.util.Delay;

public class Blink {

    public static void main(String[] args) {
        DigitalOutput led = DigitalOutput.of(ArduinoUno.getGpio().getBuiltinLed());

        while (true) {
            led.high();
            Delay.millis(500);
            led.low();
            Delay.millis(500);
        }
    }
}|}

  1. Generate

    Lower the bytecode to assembly and a runtime shim.

    ./mvnw -f juno-examples/pom.xml compile juno:compile \
  -Djuno.main=io.github.jabrena.juno.api.hardware.gpio.Blink \
  -Djuno.board=arduino-uno-r4-wifi

  2. Verify

    Compile it with the real Arduino toolchain, without touching hardware.

    ./mvnw -f juno-examples/pom.xml compile juno:verify \
  -Djuno.main=io.github.jabrena.juno.api.hardware.gpio.Blink \
  -Djuno.board=arduino-uno-r4-wifi

  3. Flash

    Upload to the board and watch the serial output.

    ./mvnw -f juno-examples/pom.xml compile juno:upload \
  -Djuno.main=io.github.jabrena.juno.api.hardware.gpio.Blink \
  -Djuno.board=arduino-uno-r4-wifi
./mvnw -f juno-examples/pom.xml juno:monitor \
  -Djuno.board=arduino-uno-r4-wifi
