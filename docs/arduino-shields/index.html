      Arduino Shields

      A shield plugs onto a board's headers and adds hardware the board does not have. Juno drives each one from plain Java: most need no Arduino library, and every shield class hands its pins and devices to the program, so a unit test can pass mocks instead. Seat a shield directly on the board, and check the pins before stacking two.

      TFT Touch Shield

      The ELEGOO 2.8" shield: a 240 × 320 ILI9341 color display on an 8-bit parallel bus, a resistive touch panel and a microSD socket. TftTouchShield draws, prints text and reads touches, and ParallelBus streams pixels from the runtime. Juno's games run on it.

      This complete example paints a blue screen, then draws a red dot wherever the screen is touched:

      import io.github.jabrena.juno.hardware.device.tft.TftTouchShield;
import io.github.jabrena.juno.hardware.serial.BaudRate;
import io.github.jabrena.juno.hardware.serial.Serial;
import io.github.jabrena.juno.util.Delay;

public final class TftTouchExample {
    public static void main(String[] args) {
        Serial.begin(BaudRate.BAUD_115200);
        TftTouchShield tft = new TftTouchShield();
        tft.fillScreen(TftTouchShield.BLUE);
        tft.setCursor(20, 20);
        tft.setTextColor(TftTouchShield.WHITE, TftTouchShield.BLUE);
        tft.setTextSize(2);
        tft.println("Touch the screen");

        while (true) {
            if (tft.readTouch()) {
                tft.fillCircle(tft.touchX(), tft.touchY(), 4, TftTouchShield.RED);
            }
            Delay.millis(30);
        }
    }
}

      TouchPaintTFT is a fuller paint program with a color palette and touch diagnostics.

      Grove Base Shield

      Seeed Studio's passive adapter: every Grove socket is an ordinary UNO pin, and GroveBaseShield names them. Plug a Grove module in and pass the socket's getter to its driver. See Grove for the sensors.

      With a Grove DHT22 module in socket D4, this complete example prints temperature and humidity:

      import io.github.jabrena.juno.hardware.device.grove.GroveBaseShield;
import io.github.jabrena.juno.hardware.device.grove.sensors.GroveDht22;
import io.github.jabrena.juno.hardware.serial.BaudRate;
import io.github.jabrena.juno.hardware.serial.Serial;
import io.github.jabrena.juno.util.Delay;

public final class GroveDht22Example {
    public static void main(String[] args) {
        GroveBaseShield shield = new GroveBaseShield();
        GroveDht22 sensor = new GroveDht22();
        int[] reading = new int[GroveDht22.READING_LENGTH];
        int[] frame = new int[GroveDht22.FRAME_LENGTH];
        Serial.begin(BaudRate.BAUD_115200);

        while (true) {
            if (sensor.read(shield.getD4(), reading, reading.length, frame, frame.length)) {
                Serial.print("temperature tenths C=");
                Serial.print(reading[GroveDht22.TEMPERATURE_TENTHS_CELSIUS]);
                Serial.print(" humidity tenths %= ");
                Serial.println(reading[GroveDht22.HUMIDITY_TENTHS_PERCENT]);
            } else {
                Serial.println("DHT22 read failed");
            }
            Delay.millis(2000);
        }
    }
}

      GroveDht22Monitor formats the two values as degrees and percent.

      Arduino 9 Axis Motion Shield

      A Bosch BNO055 that fuses its accelerometer and gyroscope and reports the heading in degrees. NineAxisMotionShield reads it over I2C with no Arduino library, which suits measuring how far a vehicle has turned. It holds D7 as the sensor's reset line.

      Constructing the shield initializes it and prints its heading, yaw rate and acceleration:

      import io.github.jabrena.juno.hardware.device.imu.NineAxisMotionShield;
import io.github.jabrena.juno.hardware.serial.BaudRate;
import io.github.jabrena.juno.hardware.serial.Serial;
import io.github.jabrena.juno.util.Delay;

public final class NineAxisExample {
    public static void main(String[] args) {
        Serial.begin(BaudRate.BAUD_115200);
        NineAxisMotionShield imu = new NineAxisMotionShield();
        imu.reset();

        while (true) {
            Serial.print("heading=");
            Serial.print(imu.getAngle());
            Serial.print(" yaw=");
            Serial.print((int) imu.getAngularVelocity());
            Serial.print(" ax=");
            Serial.print(imu.getXAccel());
            Serial.print(" ay=");
            Serial.print(imu.getYAccel());
            Serial.print(" az=");
            Serial.println(imu.getZAccel());
            Delay.millis(200);
        }
    }
}

      NineAxisMotionShieldSerial is the same monitor with startup diagnostics.

      LCD Keypad Shield

      A 16 × 2 character LCD on D4-D9, its backlight on D10, and five buttons read through one analog pin. LcdKeypadShield needs no library.

      This complete example displays the currently pressed button on the second row:

      import io.github.jabrena.juno.hardware.device.lcd.LcdKeypadShield;
import io.github.jabrena.juno.hardware.serial.BaudRate;
import io.github.jabrena.juno.hardware.serial.Serial;
import io.github.jabrena.juno.util.Delay;

public final class LcdKeypadExample {
    public static void main(String[] args) {
        Serial.begin(BaudRate.BAUD_115200);
        LcdKeypadShield lcd = new LcdKeypadShield();
        lcd.print("Press a button");
        int lastButton = -1;

        while (true) {
            int button = lcd.readButton();
            if (button != lastButton) {
                lcd.setCursor(0, 1);
                if (button == LcdKeypadShield.RIGHT) {
                    lcd.print("RIGHT ");
                } else if (button == LcdKeypadShield.UP) {
                    lcd.print("UP    ");
                } else if (button == LcdKeypadShield.DOWN) {
                    lcd.print("DOWN  ");
                } else if (button == LcdKeypadShield.LEFT) {
                    lcd.print("LEFT  ");
                } else if (button == LcdKeypadShield.SELECT) {
                    lcd.print("SELECT");
                } else {
                    lcd.print("NONE  ");
                }
                lastButton = button;
            }
            Delay.millis(50);
        }
    }
}

      LcdKeypadDemo also reports the button code over Serial.

      AZDelivery Data Logger Shield

      A microSD socket on the UNO's SPI pins with chip select D10, plus a DS1307 real-time clock that Juno does not drive. DataLoggerShield.getSdCard() gives the card, which programs use for files and for Wi-Fi credentials kept out of the source. Its D10 is also the LCD Keypad Shield's backlight.

      This complete example creates a log file, appends a line, and reports its size:

      import io.github.jabrena.juno.hardware.device.sd.DataLoggerShield;
import io.github.jabrena.juno.hardware.device.sd.SdCard;
import io.github.jabrena.juno.hardware.serial.BaudRate;
import io.github.jabrena.juno.hardware.serial.Serial;

public final class DataLoggerExample {
    private static final String LOG = "juno-log.txt";

    public static void main(String[] args) {
        Serial.begin(BaudRate.BAUD_115200);
        SdCard sd = new DataLoggerShield().getSdCard();
        if (!sd.begin()) {
            Serial.println("SD card unavailable");
            return;
        }
        if (sd.appendLine(LOG, "Juno data logger is working")) {
            Serial.print("bytes written=");
            Serial.println(sd.size(LOG));
        } else {
            Serial.println("write failed");
        }
    }
}

      SdFileOperations also reads the file back, deletes it, and supports the Nano Connector Carrier.

      Nano Connector Carrier

      Arduino's passive carrier for the Nano ESP32: a microSD slot, four Grove sockets and a Qwiic connector, all named by NanoConnectorCarrier. See the Nano ESP32 page for its pin map and examples, including remote-controlling a LEGO RCX over infrared.

      The carrier is a pin adapter, so a complete program can use a Grove socket directly. Plug a Grove LED into the A0/A1 socket, set the carrier's voltage selector to 3.3 V, and run this blink program:

      import io.github.jabrena.juno.hardware.device.carrier.NanoConnectorCarrier;
import io.github.jabrena.juno.hardware.gpio.DigitalOutput;
import io.github.jabrena.juno.hardware.serial.BaudRate;
import io.github.jabrena.juno.hardware.serial.Serial;
import io.github.jabrena.juno.util.Delay;

public final class NanoCarrierGroveLed {
    public static void main(String[] args) {
        Serial.begin(BaudRate.BAUD_115200);
        NanoConnectorCarrier carrier = new NanoConnectorCarrier();
        DigitalOutput led = DigitalOutput.of(carrier.getGroveA0());

        while (true) {
            led.high();
            Serial.println("on");
            Delay.millis(500);
            led.low();
            Serial.println("off");
            Delay.millis(500);
        }
    }
}

      For the carrier's microSD socket, use carrier.getSdCard(); it selects D4, not the UNO shields' D10.
