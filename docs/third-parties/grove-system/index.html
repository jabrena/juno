      Grove system

      Seeed Studio's Grove system connects sensors with one four-wire cable: GND, VCC, and two signal wires, the first of which (yellow) carries the module's main signal. Juno reaches a Grove module through the shield or carrier for your board. Pick one below to see its sockets, its API and an example.
