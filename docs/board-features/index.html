      Board features

      Every board runs the same Java subset, but the hardware around the program differs. This page summarises the features that depend on the board rather than on the language: networking, Bluetooth, USB, displays, storage and shields. For the language itself, see the Java subset page.

      Notes:

      • Shield means the feature comes from an Arduino or ELEGOO shield on the board's headers: the WiFi Shield on the R3 for Wi-Fi, HTTP and the clock, and the Data Logger, TFT or LCD Keypad shields for storage and displays. See Arduino Shields.
      • Carrier means the Nano Connector Carrier, which provides the Nano ESP32's microSD slot and Grove sockets. See the Nano ESP32 page.
      • Weak means a non-cryptographic random source, suitable only for best-effort identities. See the Data types section.
      • Email STARTTLS needs an upgrade of a plain connection, which the boards without a TLS stack of their own cannot do.
      • Bluetooth LE on the Nano ESP32 and the M5Stack Cardputer reaches a Powered Up hub through the core's own BLE library: Bluedroid on the Nano, NimBLE on the Cardputer. Both are confirmed on hardware with the colour example.
      • Infrared drives a LEGO RCX from the board. The RCX needs Juno's firmware for the buttons and display text; see the LEGO ecosystem page.
