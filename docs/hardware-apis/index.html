      Hardware APIs

      API What it provides Complete example
      Delay Pausing a program for a fixed time with Delay.millis, Delay.micros and Delay.seconds. Blink
      Serial Printing and reading over USB serial, the main way to see what a program is doing on a board. SerialCounter
      Gpio Driving and reading the board's pins, with DigitalOutput and the Blink example. Blink
      IMU Reading the UNO WiFi Rev2's onboard accelerometer and gyroscope with ArduinoUno.getGyroscope() and ArduinoUno.getAccelerometer(), over the Spi bus from ArduinoUno.getSpi(); see the UNO WiFi Rev2 page. OnboardImuSerial
      SD Card Loading configuration and credentials from a microSD card at boot, and reading and writing files. SdFileOperations
      Wifi Joining a Wi-Fi network on the boards that have a radio. WifiStatus
      Time Reading UTC with LocalDateTime.now() over SNTP, and measuring elapsed time with Clock. SntpTime
      HTTP client HTTP and HTTPS requests (GET, POST, PATCH, DELETE and QUERY) with caller-owned buffers, and reading JSON responses. SingleHttpsGet
      HTTP server Serving HTTP and HTTPS requests from a program, with routing by path and a certificate on the SD card. HttpServerStatus
      Email Sending mail over SMTP with Smtp, and reading a mailbox over POP3 with Pop3Client. EmailClient
      MVC Organizing a multi-screen app with a model, views, a navigator and a router from util.mvc. MailboxCardputer
