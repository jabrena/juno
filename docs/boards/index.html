Boards

Juno compiles the same Java program for six boards through three backends: AVR for the 8-bit UNO R3 and UNO WiFi Rev2, Thumb-2 for the Arm Cortex-M UNO R4 WiFi and UNO Q, and Xtensa for the ESP32-S3 Nano ESP32 and M5Stack Cardputer. Pick the target with the entry point's @Board annotation or with -Djuno.board=<id>.
